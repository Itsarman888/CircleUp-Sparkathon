# CircleUp — Project Plan

## Pitch
CircleUp connects college students across branches through reciprocal skill matching, helping them exchange knowledge, find peer support, and turn individual strengths into shared learning experiences.

## MVP
1. Student profile: name, branch, year, skills offered, skills wanted, session format.
2. Reciprocal match dashboard and plain-language reasons.
3. Search, branch filtering, and sorting.
4. Create and track skill-exchange requests.
5. Responsive design and clear demo-mode disclosure.

## Matching
Compare current student's wanted skills with a candidate's offered skills, and current student's offered skills with candidate's wanted skills. Rank reciprocal fit first; use format compatibility as a smaller secondary factor. Explain the exact shared skills. The current prototype uses an illustrative score and should be tested with real students.

## Three-person team
- Member 1: frontend and responsive UI.
- Member 2: Supabase schema/auth/RLS and matching logic.
- Member 3: student research, test cases, UX review, QA, demo script, and submission assets.

## Sprint
Day 1: validate problem with 5–10 students; agree on data model and wireframes.
Day 2: build profile screens and backend foundation.
Day 3: implement reciprocal matching and explanations.
Day 4: request flow, integration, responsive and security testing.
Day 5: deploy, test with sample students, record demo, submit.

AI is optional. Consider it only for converting free-text skill descriptions into suggested tags, with the student confirming them.
